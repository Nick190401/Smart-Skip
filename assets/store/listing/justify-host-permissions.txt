The content script has to read the DOM of the video player on each supported streaming site in order to find the skip button, read its label, and read the series and episode title so settings and learned timings can be filed under the right show. This is the extension's core function and it cannot work on a site it is not allowed to read. The host list is limited to the streaming services the extension supports, plus smartskipv2.kernelminds.de, which is the endpoint for the extension's remote configuration and for the optional, opt-in sharing of learned selectors and segment timings.
